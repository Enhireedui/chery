# Chery Mongolia — шинэ сайтын төсөл

Одоогийн сайт: **http://chery.sain-motors.mn** (WordPress + Elementor +
WooCommerce, Apache/Ubuntu). Түүний бүх агуулга, зураг, өгөгдлийг
`_crawl/` дотор бүрэн задалж авсан.

---

## `_crawl/` дотор юу байгаа

| Хавтас | Агуулга |
|---|---|
| `media/` | **320 зураг/файл, 376 МБ** — эх хэмжээгээр (161 png · 110 jpg · svg · jpeg) |
| `markdown/` | **18 хуудасны цэвэр markdown** (Firecrawl) — үзүүлэлтийн хүснэгт, үнэ, бичвэр уншихад бэлэн |
| `pages/` | **41 хуудасны бүтэн HTML** — Elementor-ын бодит зохиомж харах |
| `data/` | WordPress REST-ийн JSON: `pages` (37) · `posts` (5) · `product` (6) · `media` (283) · `product_cat` (9) · `product_tag` (8) · `tags` (12) |
| `media-index.json` | Зураг бүрийн `alt`, `title`, хэмжээ, MIME, хамаарах хуудас |
| `media-used-in-pages.json` | Хуудсанд бодитоор ашиглагдсан 163 эх зургийн жагсаалт |
| `urls.txt` | Сайтын бүх 143 URL (Firecrawl map) |

Дахин ажиллуулах: `node _crawl/crawl.mjs` (татсаныг алгасана) ба
`node _crawl/find-missing-media.mjs`.

## Шинэ сайт — `_build/site/` (12 хуудас)

`node _build/site-src/build.mjs` нь `content.mjs` дэх өгөгдлөөс бүх хуудсыг
үүсгэнэ. Гараар HTML засварлахгүй — өгөгдлөө сольвол бүх хуудас шинэчлэгдэнэ.

| Хуудас | Амьд сайт дээрх эх нь |
|---|---|
| `/` · `/models/` · `/models/tiggo-{2,4,7,8}.html` | нүүр ба 4 загварын хуудас |
| `/brand.html` | `brand` |
| `/service.html` (+ `#асуулт`) | `services` · `faq` · `dest-drive` нийлсэн |
| `/contact.html` | `contact-us` · `dealer` |
| **`/awards.html`** | `brand1` — шагнал, амжилтын хуудас |
| **`/compare.html`** | `compare` — **сэргээв** |
| `/news.html` | бүтэц бэлэн, нийтлэл 0 (хоосон төлөв) |

`compare` нь Motors theme-ийн логикоос сэргээгдсэн — дэлгэрэнгүйг
`_theme/EXTRACT-NOTES.md`-ээс.

**`awards.html` — анхаарах.** Энэ хуудасны эх нь `brand1` бөгөөд дээрх
«загварын үлдэгдэл» жагсаалтад андуурч орсон байсан. Бодит байдал дээр
`brand1` нь Chery-гийн **бүрэн бодит** шагналын хуудас: Fortune Global
500 #233, Kantar BrandZ, J.D. Power Triple Crown, экспортын рекорд,
NCAP үнэлгээ — бүгд эх сурвалжтай.

> ### ⚠ Энэ хуудас дизайны системээс ЗОРИУД гарсан
>
> Захиалагчийн шийдвэрээр `brand1`-ийн **гүйцэтгэлийг ч мөн бүтнээр**
> давтав. Дараах гурав нь `DESIGN-SYSTEM.md`-тэй шууд зөрчилдөнө:
>
> | Юу | Аль дүрэмтэй зөрчилдөх вэ |
> |---|---|
> | Гүйдэг улаан тууз (30 сек) | §14 «эргэлдэх текст хориотой» |
> | 0-оос өсдөг тоолуур | §14 «тоо өсгөх тоолуур хориотой» |
> | Тугны эможи 🇷🇺🇧🇷 | §8 «дүрс хэрэглэхгүй — типографи хийнэ» |
> | Улаан гарчиг 6 хэсэгт | §0.2 «улаан нь дэлгэцийн 5%-иас хэтрэхгүй» |
> | Хуудас бүхэлдээ хар | §2 «хуудсанд хамгийн ихдээ 2 хар блок» |
> | Oswald — 2 дахь фонтын гэр бүл | §1 «Poppins хасагдана, нэг гэр бүл» |
>
> **Эдгээрийг ЗӨВХӨН `awards.html`-д хэрэглэнэ.** Oswald нь бусад
> хуудсанд ачаалагдахгүй (`headExtra` дамжуулалт), гүйдэг тууз, тоолуур
> хаана ч давтагдахгүй. Нүүр, загвар, харьцуулалт, үйлчилгээ,
> холбоо барих хуудсууд дизайны системд 100% үлдсэн.
>
> Өнгө нь эх сайтын `:root`-оос **яг хуулагдсан**:
> `--red #dc342d` · `--red-dark #B5132C` · `--black #0D0D0D` ·
> `--dark #262626` · `--muted #b3b3b3` · `--light #d9d9d9`
>
> **Тууз нь `prefers-reduced-motion` үед Ч ЗОГСОХГҮЙ** — захиалагчийн
> тодорхой шаардлага. Windows-ын «Анимацийн эффект» унтраалттай
> хэрэглэгчид өмнө нь улаан зурвасны доор ГАРААР ГҮЙЛГЭДЭГ мөр харж
> байсныг ингэж арилгав (`overflow: hidden`, `animation` дүрмээс
> чөлөөлсөн).
>
> Хадгалагдсан хамгаалалтууд: тоолуур нь reduced-motion үед шууд эцсийн
> тоо харуулна; JS ажиллахгүй бол тоо HTML дотор аль хэдийн бичээстэй;
> тууз нь `aria-hidden` (дэлгэц уншигч давхар уншихгүй) бөгөөд түүний
> бүх агуулга доорх хэсгүүдэд бүтнээр давтагдсан тул мэдээлэл алдагдахгүй.

**Цэсний өөрчлөлт:** «Мэдээ» толгойн цэснээс гарч (нийтлэл 0 —
`DESIGN-SYSTEM.md` §11), оронд нь «Шагнал» орсон. `news.html` нь
хөлнөөс холбогдоно; бодит мэдээ 3 болмогц цэсэнд буцаана.

**Зээлийн тооцоолуур ХАСАГДСАН.** Түр хугацаанд `/finance.html` нэртэй
байсныг захиалагчийн шийдвэрээр бүрэн устгав — хуудас, CSS, JS, цэсний
холбоос бүгд.

Локал дээр үзэх: `node _build/serve.mjs` → http://localhost:4173
